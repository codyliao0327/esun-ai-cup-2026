選擇下列模組，查看 API 說明、參數與使用範例。

| 模組 | 功能 |
| --- | --- |
| [finlab](https://finlab.finance/docs/reference/finlab/) | 提供登入認證與憑證管理。 |
| [finlab.data](https://finlab.finance/docs/reference/data/) | 取得市場資料、管理快取並計算技術指標。 |
| [FinlabDataFrame](https://finlab.finance/docs/reference/dataframe/) | 提供資料對齊、選股條件與持倉訊號運算。 |
| [finlab.backtest](https://finlab.finance/docs/reference/backtest/) | 將持倉訊號轉成歷史回測與績效報告。 |
| [finlab.report](https://finlab.finance/docs/reference/report/) | 檢視回測績效、交易紀錄與策略報告。 |
| [finlab.ml](https://finlab.finance/docs/reference/machine_learning/) | 建立機器學習特徵、標籤與預測模型。 |
| [finlab.portfolio](https://finlab.finance/docs/reference/portfolio/) | 組合多個策略、配置權重並管理雲端同步。 |
| [finlab.online](https://finlab.finance/docs/reference/online/) | 串接券商帳戶，管理持倉與實盤下單。 |
| [finlab.plot](https://finlab.finance/docs/reference/plot/) | 繪製行情、財務資料與策略績效圖表。 |
| [finlab.analysis](https://finlab.finance/docs/reference/analysis/) | 分析策略流動性、MAE/MFE、穩定性與超額報酬。 |
| [finlab.optimize](https://finlab.finance/docs/reference/optimize/) | 搜尋策略參數並比較不同設定的回測結果。 |
| [finlab.tools](https://finlab.finance/docs/reference/tools/) | 提供事件研究與因子分析工具。 |
| [finlab.market](https://finlab.finance/docs/reference/market/) | 定義各市場的價格資料、對照指數與交易規則。 |
